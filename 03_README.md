# Hospital Patient Management Database

## Project Overview

This project involved designing and analysing a relational hospital
patient management database using MySQL.

The database stores patient, doctor and appointment information and
was developed to demonstrate SQL database management, data validation,
business analysis and reporting.

## Objectives

- Design a relational database
- Store and manage patient information
- Analyse patient demographics
- Analyse diagnoses
- Monitor doctor workload
- Analyse appointment activity
- Analyse patient billing
- Perform data-quality checks
- Create reusable SQL views

## Technologies Used

- MySQL
- MySQL Workbench
- SQL
- Microsoft Excel

## Database Tables

- Patients
- Doctors
- Appointments

## SQL Techniques Demonstrated

- SELECT statements
- WHERE filtering
- ORDER BY
- GROUP BY
- Aggregate functions
- JOINs
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- SQL Views
- Data validation
- CRUD operations

## Key Analysis

The project analyses:

- Total number of patients
- Average patient age
- Patient demographics
- Diagnosis frequency
- Doctor workload
- Appointment status
- Appointment completion rate
- Total hospital billing
- Average patient billing
- Highest and lowest patient bills
- Patients with above-average billing

## Data Quality

The project includes SQL checks for:

- Missing values
- Invalid ages
- Duplicate Patient IDs
- Repetitive patient data
- Billing data validation

## Project Files

`Hospital_Patient_Management.sql`  
Complete SQL database creation, data validation and analysis script.

`Hospital_Patient_Dataset.xlsx`  
Synthetic dataset used for the project.

## Disclaimer

This project uses synthetic data created for educational and portfolio
purposes. It does not contain real patient information.
